# BaraoTechExplode v0.19.0 · Windows x64

**[Baixar a versão compilada com console de otimização](https://github.com/wesscd/ResetExplode/raw/refs/heads/main/compilado/v0.19.0/BaraoTechExplode-v0.19.0-win-x64.zip)**

Extraia o ZIP antes de abrir `BaraoTechExplode.exe`. Feche a versão anterior normalmente para permitir a restauração das sessões temporárias. O pacote contém o .NET necessário, instruções e licença.

Em **Otimização guiada**, analise o PC, marque as caixas dos candidatos, revise e confirme. O console fixo no rodapé mostra os resultados e motivos de bloqueio. Use **COPIAR** ou **EXPORTAR** para compartilhar o diagnóstico de uma falha. Os registros são locais, em `%AppData%\ResetExplode\logs`; não há envio automático. O registro detalhado começa nesta versão, sem reconstrução retroativa das operações anteriores.
