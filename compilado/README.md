# BaraoTechExplode pronto para uso

A versão compilada atual está em **[v0.18.0](v0.18.0/)**, para Windows x64.

**[Baixar o pacote ZIP](https://github.com/wesscd/ResetExplode/raw/refs/heads/main/compilado/v0.18.0/BaraoTechExplode-v0.18.0-win-x64.zip)**

1. Baixe o ZIP e extraia todos os arquivos para uma pasta do computador.
2. Feche qualquer versão anterior do aplicativo normalmente.
3. Abra `BaraoTechExplode.exe` e aceite a solicitação de administrador.

O pacote inclui o .NET necessário, instruções e licença. A leitura de determinados sensores pode precisar do driver PawnIO, conforme explicado no aplicativo e no LEIA-ME. Este pacote é uma cópia verificada da release, sem necessidade de compilar o código-fonte.

O executável está dentro do ZIP. Há instruções, licença e SHA-256 na pasta da versão. Para publicações posteriores, consulte também as [releases do fork](https://github.com/wesscd/ResetExplode/releases).

O BaraoTechExplode é um fork do **RESET EXPLODE de Gustavo da Reset (GustavoReset)**. O fork da Barão Tech usa a base de sensores e desempenho para desenvolver diagnóstico e otimização para jogos. A licença MIT e o copyright original permanecem preservados.
